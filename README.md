# codykeegan.ai

Personal brand hub for Cody Keegan — AI Sales Partner.

Single-page link site modeled after sabrina.dev. Dark theme, cyan + magenta accents per the Darkhorse Traders LLC design system.

This site is **only** for the CodyKeegan.AI personal brand. Revenue Reclaimer, Celebrate in 360, and the Darkhorse Traders LLC portfolio brands are NOT mentioned here — per master brand file rules.

## Stack

- Pure HTML, no framework
- DM Sans + Instrument Serif (Google Fonts)
- Designed to deploy to Cloudflare Pages

## Files

- `index.html` — the page
- `avatar.jpg` — Cody's portrait (sized 200x200+ ideally) — pending upload
- `README.md` — this file

## Deploy

Pushes to `main` should auto-deploy via Cloudflare Pages once Pages project is wired to this repo.
